# 가습기 광학 센서 — 18초 시안

기존 채팅에서 제작한 정확한 MP4를 재제작 없이 보관한다. 전체 완성편이나 최종 품질 합격본은 아니다.

- 규격: 1080×1920, 24fps, 18.000초, 432프레임, H.264/AAC. 한국어 임시 TTS 포함.
- 0–4.5초: 가습기 물방울이 청정기로 이동. 4.5–9초: 설명용 센서 내부 광로. 9–18초: 물방울 산란과 수광부·감지 그래프 반응.
- 승인 문장 네 개를 자막·음성에 그대로 사용했다.
- 자산: 직접 만든 Blender 3D 정지 배경 3개에 입자·광선을 Python으로 합성. 실사 및 생성형 영상 없음. 이 시안의 기존 배경·음성·MP4를 그대로 재사용했다.
- 구성: 움직이는 합성 장면 3개, 독립적인 정지 장면 0개. 각 장면의 3D 배경 자체는 정지 렌더이며 카메라는 크롭 확대와 컷으로 연결된다.
- 영상은 24fps로 직접 합성했으며 프레임 보간·전체 배속 없음. 임시 TTS는 문장별 FFmpeg atempo 약 0.854/0.851/0.850/0.850배와 무음 패딩을 적용했다. 최종 자연 속도 음성 규격으로 합격한 버전이 아니다.
- 도구: Blender 4.3.2 Cycles CPU, Python Pillow/NumPy, FFmpeg, 로컬 sherpa-onnx/Mimic3 Korean kss_low. 음성 모델 원본: https://github.com/MycroftAI/mimic3-voices/tree/master/voices/ko_KO/kss_low (원본 LICENSE의 CC0 확인).
- 검수: 전체 디코딩 오류 0. Chromium 1배속 재생 완료, 432프레임, 드롭 0, 재생 오류 없음. 재생 중 캡처 화면 확인 및 잘린 발광부 라벨 수정.
- 한계: 실제 제품 구조·크기·시간·광학 시뮬레이션이 아니다. 설명용 과장임을 화면에 표시했다. 연속 3D 내부 진입, 물방울의 사실적 움직임, 렌더 노이즈, 상단 타이틀·자막 배치, 반복 펄스 표현은 최종 제작에서 개선이 필요하다. 임시 음성의 발음·자연스러움은 청취 검수 필요.
- 레퍼런스: 전체 공간 → 내부 → 미세 작동이라는 제작 지시의 전개를 적용했다. 이번 제작에서 레퍼런스 영상을 직접 재생 분석하지 않았으므로 특정 영상의 타임코드 적용을 주장하지 않는다.
- 제작 약 12분, 추가 구매·유료 API 지출 0원. 토큰 및 실행환경 비용은 확인 불가.

건강 위해성이나 실제 먼지 농도값을 주장하지 않는다. 공개 저장소 보관은 사용자의 별도 승인에 따라 수행한다.
