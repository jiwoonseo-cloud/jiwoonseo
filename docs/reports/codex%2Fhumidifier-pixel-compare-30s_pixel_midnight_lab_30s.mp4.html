# 가습기 픽셀 시안 B: 야간 미니어처 실험실

30초 독자 스타일 검토본이며 전체 대본의 완성본은 아닙니다. '작은 세계의 원리'는 임시 화면 표기입니다.

- 영상: 1080×1920, 24fps, H.264 High Level 4.1, yuv420p, AAC 48kHz 모노.
- 음성: A와 동일한 한국어 M1 음성의 연속 첫 26.75초를 원래 속도로 사용합니다. 마지막 3.25초는 동작을 이어갑니다.
- 승인 대본 첫 여섯 문장과 한국어 자막을 사용합니다. 배경음과 효과음은 없습니다.
- 밤의 생활 공간 → 공기청정기 표시 변화 → 물통 → 분무 매크로 → 초음파 진동판 단면 → 액체 방울 → 흡입구 → 광학 센서 단면.
- 주요 공간 7종, 편집 구간 11개. 남색·청록·크림 팔레트를 사용합니다.
- Python, Pillow, FFmpeg로 모든 시각 자산과 720프레임을 직접 그렸습니다. 360×640 픽셀 좌표계에서 최근접 3배 확대했으며 짧은 동작 클립 늘이기나 프레임 보간을 사용하지 않았습니다.

## 정확성 및 검증 범위

초음파 분무는 작은 액체 방울입니다. 진동판, 수면 파동, 방울의 크기·속도는 개념 연출입니다. 센서 장면에서 방울은 중앙 공기 통로를 지나며 빛을 가로지를 때 산란 경로와 표시 신호가 켜집니다. 방울이 수광부에 닿는 구조로 표현하지 않았습니다.

파일 규격, 전체 프레임 디코딩, 자막 원문 일치, 대표 프레임을 확인했습니다. 일부 제품 원근과 비례는 간략화되어 있습니다. 실제 청취 검수와 iOS 실기기 재생은 미검증이며 기술 검증만으로 시각·청취 품질 합격을 선언하지 않습니다.
