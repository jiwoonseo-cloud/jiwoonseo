## 시험에서 고친 점
- 정수로 저장되던 감김 제어값을 float로 수정하여 중간 상태가 연속적으로 변하게 했습니다.
- Python으로 점 좌표만 갱신하던 방식은 렌더 중 머리카락 형태가 멈추었습니다. 2,036개 프레임의 Curve 형태를 Blender native shape key로 구워 실제 렌더 변형을 확보했습니다.
- 36개의 독립된 가는 Curve 가닥(가닥당 96점)으로 감김과 축 방향 이동을 만들었습니다. 단일 띠나 튜브가 아닙니다.
- 끝단 캡에 가려지던 경로는 카메라를 브러시 안쪽으로 옮겨 수정했습니다.
- 다음 대상의 자막이 일찍 나타나던 구간을 문장 경계로 나눴습니다.
- 시험 0–3초: 가닥이 브러시에 걸려 감김. 4–7초: 회전하면서 축 방향 이동. 8–9초: 반투명 축과 끝단 베어링 사이로 다발 접근. 마지막 프레임에서 축 쪽 작은 다발 상태 확인(test-end-frame.jpg).
- test-10s.mp4와 test-contact-sheet.jpg가 실제 240프레임 렌더 결과입니다. native-mesh-check.json과 geometry-audit.json은 보조 검사이며 시각 품질 판정의 대체 수단으로 쓰지 않았습니다.

- 전체 구도 검수에서 잘리던 본체와 너무 작던 흡입 경로를 수정했습니다. 원래 렌즈값을 참조하던 투영 계산을 현재 카메라의 view frame 기준으로 고쳤습니다.
- 관리 손의 뾰족한 끝을 둥글게 모델링하고, 가위 접촉점을 가리던 손을 손잡이 쪽으로 옮겼습니다.

- 관리 장면에서 본체 외곽과 분리 브러시가 겹치던 배치를 수정했습니다. 본체를 뒤로 옮기고, 장착 상태의 브러시 위치와 재조립 카메라도 함께 맞췄습니다.

- 흡입 설명에서 긴 모발이 먼지 경로보다 강하게 보이던 문제를 고쳤습니다. 해당 94프레임에서는 긴 모발을 숨기고 먼지 입자를 밝고 크게 표시하여 실제 흡입 경로에 시선이 가도록 해당 94프레임을 포함한 8번 렌더 구간(199프레임)을 다시 렌더했습니다. 정상 완료된 고유 프레임 범위는 유지하며 같은 구간을 영상 안에서 반복하지 않습니다.

## 장면 표
전체 단어별 발화 시간은 합성 시 제공된 TTS WordBoundary인 audio/*.json이며 별도 ASR 강제 정렬 결과는 아닙니다. 58개 렌더 구간의 타임코드·내레이션·대상·시작→움직임→끝 상태는 scene-table.csv에 있습니다. 실제 프레임 경계도 함께 기록했습니다. 최종 렌더 로그로 각 프레임의 컷과 카메라를 추적할 수 있습니다.

## 컷 수
실제 카메라 샷은 동작 57샷, 정지 0샷입니다. 렌더 표의 P5-C03·C04는 같은 시점의 카메라를 이어 쓴 3.9초짜리 단일 흡입 경로 샷입니다. 이를 합친 최종 장면 표는 shot-table.csv이며, 58행 scene-table.csv와 motion-audit.json은 내부 렌더 구간 기준입니다. 발견·생활 맥락 컷에는 미세한 손·제품 움직임이 포함되어 원리 동작과 같은 강도로 움직인다는 뜻은 아닙니다. 카메라 변화를 이 수치에 포함하지 않았습니다. 최종 화면 검수는 별도로 기록합니다.

## 제작과 재사용
영상은 Blender EEVEE로 직접 만든 3D 장면입니다. 1080×1920, 24fps, 실제 전체 시간에 필요한 프레임을 렌더합니다. 정지 이미지, 영상 루프, 크롭 재활용, 프레임 보간, 슬로모션 늘이기를 사용하지 않습니다. 음성과 단어 타임코드는 앞서 전송 허가받아 합성한 자료를 재사용했습니다. 제품 자산은 일관성을 위해 재사용하며 동작 클립을 반복하지 않습니다. 손·제품·금속 베어링·플라스틱·고무·바닥은 직접 모델링/재질 설정했습니다. 실제 제품 사진·로고는 쓰지 않았습니다. 설명용 저속 원리 구간은 화면에 표시합니다. 배경음과 컷 효과음은 낮게 합성한 자체 신호입니다.

## 남은 약점
모발은 물리 시뮬레이션으로 검증한 실제 제품 실험이 아니라 기하학적으로 설계한 원리 연출입니다. 손가락 접촉은 근사한 관리 동작이며 실제 인체 촬영 수준은 아닙니다. 소프트웨어 렌더 한계로 EEVEE 1 sample과 분석적 접촉 그림자를 사용하여 가는 모발의 계단 현상·노이즈와 재질의 단순함이 남을 수 있습니다. 실제 제품별 반대 회전·절단 방식의 사실 문제는 fact-check.md에 보존했고 6번은 보류했습니다. 관리 주기는 기종 설명서·오염에 따라 달라진다는 고지를 영상에 넣습니다.

프레임 추출과 발화 타임코드를 중심으로 검수했습니다. 실시간 연속 재생에서의 청감 검수는 수행하지 못했습니다.
