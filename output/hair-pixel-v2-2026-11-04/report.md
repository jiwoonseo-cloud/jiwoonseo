1. 중앙 타원 복제와 좌우 흔들림 코드를 폐기했다. 새로 생성한 대상의 실제 외곽 알파만 사용하고 배경판은 고정했다. 물체가 하나인 장면에서 원본과 움직이는 사본을 겹치지 않는다.
2. 모든 장면 중앙에 덧그리던 공통 머리카락 패턴을 제거했다. 머리카락은 각 행동 원화에 포함되며 모·롤러·축과의 접촉 위치에서 상태가 바뀐다. 코드로 별도의 털 다발이나 물결 선을 그리지 않는다.
3. 컷마다 접촉 전·접촉·행동·완료 상태를 따로 제작했다. 본체 뒤집기, 가닥 걸림과 감김, 베어링 이동, 캡 분리, 롤러 추출, 절단·제거를 서로 다른 동작으로 표현했다. 완성된 동작을 반복 재생하지 않고 결과 상태를 유지한다.
4. 기존 패널을 세로로 늘이던 방식을 없앴다. 배경은 비율을 유지해 세로 화면을 채우고, 스프라이트도 비율을 유지한다.
5. 같은 브러시 하우징이 실패·청소기 본체 등으로 잘못 복제된 초기 생성 10장을 사용하지 않고, 전체 40장면을 다시 생성했다.
