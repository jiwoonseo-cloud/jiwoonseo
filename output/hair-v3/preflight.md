# 실행 전 3차 자체 검토와 반영

1. 목표 검토: 한국 20~40대의 “왜 끝단에 감길까, 어떻게 관리할까”를 행동으로 설명한다. 90~115초를 맞추기 위해 원문 삭제·후처리 배속·무음 강제 삭제를 하지 않는다. 원문 8문단, 한글 776음절을 대조해 보존했다. 브랜드 설명은 사용자 선택으로 보류했다.
2. 레퍼런스 검토: 6개 원본 영상 본문을 확보해 지정 구간의 순차 프레임을 직접 확인했다. 금속·고무·플라스틱·모발 재질 구분, 실제 분리 후 공개, 하나의 대상이 끝까지 이동하는 경로를 가져온다. 상단 키워드 반복을 제거하고, 숫자 라벨은 최종 사실 검증을 통과한 수치 컷 최대 2~3개로 제한한다. 해당 숫자가 없으면 임의 숫자를 만들지 않는다.
3. 구현 검토: Blender 4.3.2와 FFmpeg 사용 가능. 직접 모델링한 제품·롤러·개별 곡선 모발을 실제 프레임 시각에 따라 계산한다. 첫 시험은 뒤집기·걸림/감김·바닥에서 흡입구 진입이다. Cycles 빌드에 내장 디노이저가 없어 렌더링이 실패한 것을 확인하고 해당 옵션을 껐다. 렌더러 성능과 미세 모발의 가시성을 먼저 검증하며, 실패한 시험을 전체 길이로 늘이지 않는다.

가장 중요한 확인: 자연 속도 오디오와 전체 발화 경계가 없으면 최종 시간표를 확정하지 않는다. 미측정 길이를 실측으로 보고하거나 시험 3초 동작을 긴 대사에 늘여 쓰지 않는다.
