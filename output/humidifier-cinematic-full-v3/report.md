# 가습기 × 공기청정기 — 시네마틱 전체 대본 v3

승인 대본 전체를 포함한 1080×1920, 24fps 영상입니다. 본 파일은 전체 길이 제작본이지만 **음성 실제 청취 검수는 미완료**이므로 검수 완료 최종본으로 승인하지 않았습니다.

## 제작과 검증

- 음성 길이: 129.1335초(문장 사이 여백 포함). 최종 인코딩 영상 129.083초, 오디오 스트림 129.069초. 마지막 발화 뒤 여백이 남아 있습니다.
- 승인된 26문장을 그대로 보존했습니다. 자막 조각을 이어 붙여 모든 문장의 공백 제외 문자열 일치를 검사했습니다. 문장·표현을 임의로 고치지 않았습니다.
- MeloTTS Korean 기본 화자, CPU 로컬 추론, speed/length_scale 1.0. 보이스 복제·학습·파인튜닝·후처리 배속·무음 강제 삭제 없음. 문장 간 0.26/0.5초 여백 추가.
- 모델 attention duration을 이용해 2–3어절 단위 자막 시간을 계산했습니다. 흰 굵은 자막+어두운 테두리, 높이 66.7%, 배경 박스 없음.
- 26개의 대사 cue가 15개 의미·행동 구간을 구성합니다. 전 구간에 입자 이동·산란·증발·표시 변화 등의 동작을 배치했고 순수 정지 컷은 없습니다. 원본 18초 영상의 반복 재생이나 슬로모션 연장은 사용하지 않았습니다. 원리상 주기적인 분무/광로 통과 동작은 반복됩니다.
- 원본 full의 고정 카메라·정면 센서 구도와 동일한 이미지 패널을 사용했습니다. 청록색 외곽선 대신 실제 배경 픽셀 굴절과 따뜻한 Fresnel 반사/하이라이트를 합성했습니다. 광선에도 부드러운 번짐을 적용했습니다.
- 물방울 중심은 광로를 통과한 뒤 수광부 왼쪽으로 지나갑니다. 수광부와 물방울의 물리적 접촉으로 인식하는 연출은 없습니다. 광로 교차 때에만 산란광과 수광부 반응이 발생합니다.
- 물방울 검출과 증발 후 고체 잔류를 별개 과정으로 표시했습니다. 표시 예시 수치는 실측값이 아닙니다. 녹아 있는 성분을 보여 주는 점들은 화면에도 명시한 개념 표현입니다.
- 낮은 합성 배경음/전환 효과음을 로컬에서 만들었습니다. 실제 기기 작동음이라는 의미는 없습니다. 내레이션은 loudnorm -18 LUFS 목표, -2 dBTP 제한으로 처리했습니다.

## 확인한 자료와 재사용 범위

Library의 artifact_repair_v2_sources.zip 및 papermorph_8styles_sources.zip을 이번 실행 환경에 prepare_materialize와 공식 전송 helper로 내려받았습니다. ZIP 두 개의 CRC 검사 통과, 실제 파일 읽기 확인. 원본은 sources/ 아래에 보존했습니다.

실제 픽셀 확인: full/review/final_contact.jpg, full 기준 프레임, art/cinematic-storyboard.png, 새 센서/미네랄/수면 프레임 및 새 영상 추출 프레임. 기존 full/image_styles.js에서 카메라 고정, 같은 센서 패널 재사용, 발광부·수광부 배치 원칙을 확인했습니다.

이번 영상은 제공된 시네마틱 이미지 자산 + 새 절차적 2D 합성입니다. 실사 촬영이나 완전한 물리 기반 3D 시뮬레이션이 아닙니다. 원본 이미지가 어떤 생성기로 제작됐는지는 이번 자료만으로 확정하지 않았습니다. Veo 실행·유료 이미지 생성·모델 학습은 하지 않았습니다. Instagram 레퍼런스 원본 영상은 이번 작업에서 열람하지 않았으므로 분석했다고 주장하지 않습니다.

## 무료 TTS 조사 및 비교

| 방법 | 확인한 조건 | 이번 선택 |
|---|---|---|
| MeloTTS Korean | 코드와 한국어 모델 카드 MIT, 로컬 CPU 추론 | 사용. 26문장 약 129초 생성. 음성 복제 불필요 |
| Meta MMS Korean | CC-BY-NC 4.0, 로컬 사용 가능, 로마자 전처리 필요 | 비상업 제한이 있어 범용 제작본의 기본값으로 선택하지 않음 |
| edge-tts | Edge 온라인 TTS를 호출하는 비공식 클라이언트 | 라이브러리 설치만 했고 서비스 호출/음성 생성은 하지 않음. 저장 음성의 배포 권리를 이번 조사로 확정하지 못해 제외 |
| 기존 시안 음성 | 메타데이터에는 'PR18 existing temporary audio'만 기재 | 목소리 출처·조건·자연스러움 미확인. 전체 음성은 새로 생성 |

이는 조건·실행 방식 비교입니다. **청취 기반 자연스러움 비교를 완료했다는 뜻이 아닙니다.** 사용 가능한 도구 목록에 음성 입력/청취 기능이 없어 실제로 듣고 판단할 수 없었습니다. 정상 속도 실제 청취와 어색한 발음 수정은 남은 필수 검수입니다.

보조 검사로 Whisper small을 로컬 실행했습니다. 공백·구두점을 제외한 문자열 유사도는 0.946886(원문 545자, 인식 547자)이었습니다. 특히 '흩뜨립니다', 마지막 문장의 '방울이 흩뜨린' 등에서 다른 문자열이 인식됐습니다. ASR 오류인지 합성 발음 문제인지는 청취 없이 판정하지 않았습니다. asr_check.json에 전체 결과가 있습니다. 자막은 ASR 결과로 바꾸지 않았습니다.

## 한계·비용

새 매크로 장면은 원본 시네마틱 배경보다 합성/개념도 성격이 강합니다. 물리 기반 유체/광학 시뮬레이션이나 Veo 수준 사실성 검증을 주장하지 않습니다. 표면·미네랄 표현은 과학 설명을 위한 단순화입니다.

유료 API 호출 0회, 결제 0회, Veo 사용 0회. 로컬 모델/패키지 다운로드와 CPU 추론·FFmpeg/Pillow 합성만 사용했습니다. 플랫폼 토큰 및 실행 환경 비용은 표시되지 않아 확인 불가입니다. 초기 입력 확보는 2026-11-05 11:48 UTC경이며 실제 종료 시각은 delivery_manifest.json에 기록합니다.

공개 범위는 승인된 영상과 제작 코드/보고서만으로 제한합니다. 자격 증명, 모델 캐시, 환경 파일, 관계없는 업무 데이터는 포함하지 않습니다. 원본 사이트 병합·배포는 수행하지 않으며 draft PR은 별도로 기록합니다.

최종 H.264/AAC MP4 전체 디코딩 오류 0건, 실제 출력 프레임 8개 픽셀 확인, 음성/영상 종료 차이 0.015초 미만을 확인했습니다. 이 검사는 실제 청취나 정상 속도 재생 관찰을 대신하지 않습니다.

`tts_comparison.mp3`에는 동일 문장의 기존 시안 음성 → 1초 간격 → 새 MeloTTS 음성 순으로 담았습니다. 비교용 파일 제공이며 청취 평가 결과는 없습니다.
