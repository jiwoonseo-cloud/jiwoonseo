# 가습기 픽셀 시안 A: 레퍼런스 제작 방식

30초 검토본이며 전체 대본의 완성본은 아닙니다.

- 영상: 1080×1920, 30fps, H.264 High Level 4.0, yuv420p, AAC 48kHz 모노.
- 음성: 공통 비교용 한국어 M1 음성의 연속 첫 26.75초를 원래 속도로 사용합니다. 마지막 3.25초는 동작을 이어갑니다.
- 승인 대본 첫 여섯 문장과 한국어 자막을 사용합니다.
- 고정 생활 공간 배경, 별도 제품·물방울 자산, 분무 확대, 초음파 진동 단면, 센서 내부 이동을 연결합니다.
- 배경과 기기 자산은 직접 생성·작성했으며 특정 창작자의 캐릭터·로고·배경은 복제하지 않았습니다.
- 한국어 내레이션에 직접 합성한 작은 효과음과 낮은 배경음을 더했습니다.

## 정확성 및 검증 범위

초음파 가습기의 분무는 작은 액체 물방울입니다. 물방울 크기, 진동·증발 속도, 센서 구조는 이해를 위한 개념 연출이며 특정 제품의 실제 크기·구조를 재현하지 않았습니다. 미세먼지 수치를 임의로 제시하지 않습니다.

파일 규격 확인 및 전체 프레임 디코딩을 통과했습니다. iOS 실기기 재생과 시청자 관점의 시각·청취 품질 합격은 별개이며 아직 확인하지 않았습니다.
