# 제작 코드

scene.py: 고정 3D 제품·부품과 원리별 애니메이션. Blender 4.3.2에서 실행.
layers.py: 투명 PNG 부품의 독립 이동.
prepare.py: 원문 보존 검사, 단어 경계 기반 풀 자막, 실측 타임라인·음향.
denoise.py: OIDN 노이즈 제거.
assemble.py: FFmpeg 보간·컷 조합·자막·음성 합성.
tts_words.py: SunHi 한국어 TTS +10%, 단어 경계 수집.

코드는 이번 실행 환경의 절대 경로를 그대로 기록한 제작 기록이다. 다른 환경에서 재실행하려면 P(작업 폴더), O(저장소 output/hair-v2), TTS 라이브러리·CA 경로와 기준 이미지 입력 경로를 수정해야 한다. 영상 소스의 노이즈 제거 전 렌더 프레임은 저장소 크기를 줄이기 위해 제외했다. 같은 Blender 코드로 다시 렌더할 수 있다.

입력 자산은 ../assets, 합성된 문단별 원음과 단어 시각은 ../audio에 보존했다. TTS 음성에는 후처리 atempo를 사용하지 않았다. FFmpeg의 setpts는 부품 애니메이션을 컷 길이에 맞추는 영상 처리에만 사용한다.
