# 가습기 종이 스타일 개선본 v5

승인 대본 전체를 유지한 109.375초 영상. 기존 v3는 보존했다. 이번 버전은 화자 자연스러움의 청취 합격본으로 표시하지 않는다.

## 사용자의 지적에 따른 수정

1. 글자 겹침: 상속된 모든 제목·주석을 먼저 제거하고 필요한 리더선 주석만 새로 배치했다. 그림은 y=1430 아래에 그리지 않으며, 자막은 y=1535에 고정했다. 71개 구절 자막의 최대 폭은 739px로 1080px 화면 안에 충분히 들어간다. 자막은 흰색 굵은 글자와 어두운 테두리이며 강조 색·박스는 없다.
2. 빨간 변화: 기존 작은 막대를 제거하고 큰 단일 전면 표시등으로 교체했다. 기존 초록 막대가 겹쳐 보이지 않는다. 음성의 '빨갛게' 시점 약 2.94초에서 초록→빨강으로 변한다. '상태 표시등' 리더선은 이 표시등에 끝난다.
3. 먼지 센서 선: 센서 입구를 별도의 파란 원형 포트로 유지하고 주황 테두리·명확한 선 끝점을 붙였다. 주석도 '먼지 센서 입구'라고 표시하여 표시등과 구분했다. 엉뚱한 흡입 그릴을 가리키던 보조 화살표는 삭제했다.
4. 물자국 연속성: 젖은 막과 마른 미네랄 테두리를 완전히 같은 MARK 좌표로 그렸다. 젖은 막은 동일한 경계 안에서 얇아져 사라지며 흰 흔적이 같은 경계에 남는다. '마르고 나면' 전에는 젖은 상태를 유지한다.
5. 상단 PPT식 제목: 전 구간에서 삭제했다. 필요한 부품 주석은 부품 옆에만 둔다.

## 템포와 원인 결과

v3의 134.625초에서 109.375초로 25.25초 짧아졌다. 인코딩된 원본 영상을 배속하거나 반복하지 않고 모든 프레임을 다시 그렸다. 물 붓기, 분무 확대, 진동판/수면 교란, 액체방울 확대, 센서 입구, 광원/통로, 먼지 산란, 빛→전기 신호 변환, 물방울 산란, 신호의 성분 한계, 표시 상승, 성분 드러내기, 녹아 있는 미네랄, 수면에서 함께 방출, 공중 운반, 증발/잔류, 동일 물자국 건조, 두 과정 비교, 결론을 동작 중심으로 구성했다. 고정된 센서 구도에서 입자가 광선을 지나며 산란한다. 검출기와 물질은 접촉하지 않는다.

26개 발화 구간을 사용하되 연속 설명이 필요한 센서와 물방울 성분 드러내기 장면은 상태를 이어 간다. 짧은 전환은 0.16초이며 카메라 줌만으로 원리 동작을 대신하지 않는다. 결론의 재등장은 승인 대본의 복귀 구조에 따른 것이다.

## 음성과 자막

- 최종 음성: 제공된 Supertonic M1 `libfile_4b0439f33be08191805fc4e43b43c1db`, 제공 문단 SRT `libfile_3abd3b2a8d348191bb0adf65420c4faf`. 원본 48kHz mono PCM16, 109.37초.
- 선택 근거: 사용자가 세 번째 남성 음성을 상대적으로 선호했다는 전달된 평가와 실제 길이. 직접 청취로 더 자연스럽다고 판정한 것은 아니다.
- 이 실행에서 별도 MeloTTS 빠른 발화 설정 1.15로 117.13초 후보도 새로 합성했지만 최종에는 쓰지 않았다. 기존 파일 후처리 배속은 두 후보 모두 하지 않았다.
- 최종 음성은 제공된 M1 속도 그대로다. loudnorm과 낮은 자체 합성 효과음만 적용했다. 음악·외부 효과음 없음. 화자 복제·훈련·파인튜닝·Veo·유료 API 없음.
- 문단 경계와 로컬 faster-whisper small의 단어 시점을 대조해 26개 발화 시작과 71개 자막 구절을 배치했다. ASR 출력으로 대본을 바꾸지 않았다. 공백을 제외한 자막/대본 문자열은 완전히 일치한다.
- ASR의 문단별 문자 일치율은 95.2–100%다. '수증기', '흩뜨립니다', '흩뜨린', '읽고'가 다른 단어로 인식된 부분은 실제 발음 문제인지 인식 오류인지 구분하지 못했다. 실제 청취 검수 미완료이며 이 인식률을 음성 자연스러움 점수로 해석하면 안 된다.

## 레퍼런스 확인 범위

직접 픽셀로 확인한 자료는 원본 paper v2의 연락 시트, v3의 초반/센서/물자국 프레임, 새 v5의 인코딩 후 9개 핵심 프레임과 물자국 3단계 비교다. 특히 이전 젖은 수평 타원과 기울어진 불규칙 잔류 테두리의 불일치를 확인하고 동일 좌표 방식으로 교체했다.

외부 Instagram 링크 Dego8e3zJOm, DeHPHqVog5H는 조회가 throttled되어 원본 재생을 확인하지 못했다. Know_n_eat https://www.youtube.com/watch?v=zMSHpXRUNX0 의 0–23초 감자→반죽→롤러→성형→튀김 상태 변화 관찰과 TechNote의 지속적인 물체 작동 관찰은 부모 작업에서 전달된 레퍼런스 검토이며, 이 실행에서 직접 봤다고 주장하지 않는다. 적용한 것은 동사에 맞춰 물체 상태가 바뀌도록 구성하는 원칙이다.

## 검증과 비용

1080×1920, 24fps, H.264/AAC. 전체 FFmpeg 디코딩, 승인 대본 26개 발화/71개 자막 문자열 일치, 원본 음성 클리핑 0개 확인. 녹아 있는 성분은 개념 표시 점으로, 물이 사라진 뒤에만 고체 모양으로 나타낸다. 축척·시간 조정 고지는 화면 하단에 작게 남겼다.

과학 근거는 v3와 동일: Sensirion 광산란 센서 원리 https://sensirion.com/products/product-insights/specialist-articles/particulate-matter-sensing-for-air-quality-measurements, EPA 가습기와 미네랄 분산 https://www.epa.gov/sites/default/files/2014-08/documents/humidifier_factsheet.pdf. 센서 표시만으로 물질 성분이나 위험도를 판단할 수 있다는 주장은 하지 않는다.

실행한 유료 API 없음. 플랫폼 컴퓨팅·토큰 요금은 표시되지 않아 확인 불가. 작업 중 예상은 20–30분으로 안내했다. 실제 렌더 측정은 render.log에 기록한다.

## 재현 파일

render_v5.py, paper_base.py, render_extensions.py가 화면을 생성한다. narration.wav는 최종 제공 음성, mix_sound.py는 낮은 효과음/음량 처리를 만든다. mix.wav와 timing.json, aligned_captions.json을 사용해 같은 시간축으로 재렌더할 수 있다. 모델 가중치, 가상환경, 비밀정보는 공개 파일에 포함하지 않는다.
