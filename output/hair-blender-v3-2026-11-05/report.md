## 피드백을 반영한 제작 방식

이전 생성 이미지와 픽셀 스프라이트는 재사용하지 않았다. 흰 원형 본체, 범퍼·센서·구동륜, 프로파일을 가진 롤러 코어와 고무 핀, 개별 나일론 모, 캡·베어링 볼, 두 짧은 롤러, 절단 빗, 손, 가위, 모터 권선, 거실을 Blender에서 모델링했다. 재질은 Principled BSDF의 플라스틱·고무·금속 거칠기와 반사를 구분했다. 손은 결합·리메시한 유기적 표면이다.

긴 머리카락은 native Hair Curves의 개별 가닥이다. 최종 주 설명 롤러는 90가닥, 가닥당 168개 제어점이며 장면의 목적에 따라 가닥 수를 다르게 사용했다. 브러시 모는 별개의 짧은 나일론 곡선이다. 회전 스핀들과 머리카락의 감김·자유 길이·축 방향 위치는 키프레임과 Geometry Nodes로 연결했다. 가위 컷에서는 곡선 자체를 여러 조각으로 분리하고, 절단 뒤 가닥이 느슨하게 풀리며 손을 따라 이동한다. 단일 띠나 튜브가 아니다.

EEVEE에서 실제 3D 상태를 매 프레임 렌더했다. 고정 카메라 장면의 변하지 않는 배경만 캐시했다. 물체·가닥·면광원 그림자의 모든 프레임 투영 범위에 여유를 더한 영역을 원래 1080×1920 픽셀 좌표로 다시 렌더해 합성했다. 고정 배경 경계의 64픽셀 완화만 적용했다(물체 경계까지 96픽셀 안전 여백 내부). 움직이는 원형 마스크, 그림 복제, 2D 흔들기, 카메라 줌으로 동작 대체, 프레임 보간·반복 재생은 사용하지 않았다. 카메라가 전환되는 장면과 필요한 장면은 전체 화면 렌더다. `source.zip`의 각 `.blend`는 키프레임·곡선 리그가 들어 있으며 Python 프레임 콜백 없이 재생된다.

조명은 소프트 면광원 세 개, 카메라는 고정 초점의 얕은 심도다. 자막은 단어 정렬에 따라 2~3어절씩 후합성했다. 공간 노이즈 정리와 작은 안티앨리어싱 블러는 프레임별 후처리이며 새 동작 프레임을 만들지 않는다. 배경음과 효과음은 외부 샘플 없이 직접 합성해 음성보다 낮게 믹싱했다.

## 음성 먼저, 단어에 동작 맞추기

생성한 실제 PCM 음성을 MMS CTC 음향 모델에 넣고 원문을 uroman 토큰으로 변환해 Viterbi 강제 정렬했다. 문장 글자 수나 임의 비례 배분으로 단어 시간을 만든 것이 아니다. `word_timecodes.csv`와 `scene_table.csv`에 실제 경계를 제공한다. 24fps의 표현 단위는 약 41.7ms이며 자동 음향 정렬에는 작은 경계 오차가 있을 수 있다.

‘돌아가면’ 22.6377초부터 먼저 스핀들이 회전하고 ‘모에’ 24.1784초부터 가닥이 모로 접근한다. 핵심 동작은 ‘걸립니다’ 24.4185초에 시작, ‘회전할’ 26.1992초부터 감긴 길이가 증가한다. ‘끝단’ 31.2213초부터 다발이 끝단으로 이동하며 ‘베어링 쪽으로’ 31.9416–32.6419초에도 이동 중이다. ‘모입니다’ 33.1822–33.6424초 구간에 홈에 모이는 동작을 끝낸다. 대상 이름만 자막으로 붙여 놓고 다른 물체를 보여 주는 방식은 쓰지 않았다.

## 10초 시험과 수정

`source.zip`의 `review/trial_10s.mp4`는 원음 24.125–34.125초에 대응하는 감김·이동 시험이다. 240프레임을 렌더한 뒤 실제 인코딩 영상에서 1초 간격 10장과 마지막 프레임을 추출해 `trial_contact.jpg`로 직접 확인했다.

첫 시험은 접촉점이 롤러 뒤에 가리고 카메라가 너무 가까워 실패로 판단했다. 가닥을 전면에서 아래로 늘어뜨리고, 회전하면서 위로 끌어올리도록 바꿨다. 자유단을 가리는 공급판을 제거하고 카메라를 넓혔다. 정면 접촉 → 감김 매크로 → 위에서 본 중앙 이탈 → 투명 단면의 끝단 이동 순서로 고쳤다. 자유단이 바닥에 닿는 픽셀도 매 프레임 다시 렌더했다.

시험본에서 확인한 것은 ① 가는 개별 가닥 ② 실제 롤러 회전과 자유 길이 감소·축 이동 ③ 발화 시간에 해당 동작이 진행되는지다. 전체 렌더의 뒤집기 컷을 추가 검토했을 때 ‘브러시’ 발화 중 윗면이 대상을 가리는 문제를 찾았다. 본체를 먼저 충분히 올리고 반대 방향으로 뒤집도록 바꿔 4.2095초의 ‘브러시’ 발화 때 하부가 보이게 했으며, 바닥과의 겹침도 없앴다. 이 컷은 최종 출력 전에 다시 렌더했다. 전체 검수에서 ‘돌아가면’ 발화 때 정지해 있던 초기 스핀들과, 22번에서 감긴 뒤 축으로 미끄러질 때 멈추던 스핀들도 찾아 다시 렌더했다. 감김이 끝나도 이동 중에는 회전이 이어지도록 맞췄다. 새 22번 네이티브 렌더의 마지막 상태에서는 다발이 화면 밖으로 나가 사라진 것처럼 보이는 추가 문제를 찾았다. 카메라를 끝단을 바라보는 반대 사선으로 바꾸고, 중앙의 시작점과 베어링 앞 다발이 동시에 보이도록 넓힌 뒤 이 컷 전체를 다시 렌더했다.

추가 자체 검수에서 축 이동 제어값이 정수로 저장되어 중간값이 반올림되고 다발이 갑자기 이동하는 오류를 발견했다. 전체 렌더를 중단하고 키프레임 값을 모두 실수형으로 저장하도록 수정했다. 절단 후 풀림 제어에도 같은 수정을 적용했다. 이전 시험본과 해당 컷의 렌더는 폐기했다. 새 시험의 시작 프레임에서 다발 일부가 화면 가장자리에 걸리는 것도 찾아 12번 카메라를 넓히고 중앙에서 끝단까지 함께 보이게 수정했다. 그 뒤 감김·끝단 이동 10초를 다시 네이티브 렌더했다. 1초 간격 외에 끝단 이동 구간을 0.25초 간격으로 추가 추출하여 연속 이동과 발화 일치를 확인했다. `trial_slide_quarters.jpg`는 이 추가 검수 자료다.

흡입 장면 13·28번의 위쪽 구도는 관 입구가 가닥의 상승 경로를 가리는 문제도 발견해 사선 측면으로 교체했다. 새 미리보기에서 관 아래의 개별 가닥과 관 내부의 상승 경로를 직접 확인한 뒤 해당 컷을 새로 렌더했다.

28번 배출 컷의 짧은 조각은 관 안에서 너무 희미해 보여 관의 투명도를 높이고 구도를 좁혔다. 가닥 두께는 유지하면서 72개의 짧은 조각이 발화 후반까지 이동하도록 배출 시점을 늘렸다.

27번 절단 컷에서도 곡선을 분리한 뒤 모양이 그대로 함께 올라가 절단이 잘 전달되지 않는 문제를 찾았다. 절단 후 개별 곡선 조각이 풀리고 서로 다른 위치로 벌어지도록 키프레임·Geometry Nodes를 추가했다. 몸체와 겹치지 않는 앞쪽 경로로 이동하고 화면 안에 조각이 남도록 높이를 줄인 뒤 절단 이후 구간을 다시 렌더했다.

같은 Blender 제작 과정에서 수정과 무관한 네이티브 프레임은 원래 전역 시각에 보존하고 수정 대상만 다시 렌더했다. 제품·손·고양이 모델은 공유하지만 동작 클립을 다른 대사에 반복하지 않았다.

검수한 시험 렌더는 같은 전역 타임코드의 최종 프레임으로만 이어 썼다(9번 후반 28장, 10번 78장, 11번 45장, 12번 86장). 27번의 수정과 무관한 절단 전 2162–2200번 네이티브 프레임 39장도 같은 위치에 보존했다. 다른 대사 구간으로 클립을 복제·반복하지 않았다.

마지막 40번도 ‘모터를’ 발화 때 깨끗한 축만 보이던 문제를 찾아, 139.8583초에 연결 모터와 정리된 축이 함께 보이는 구도로 전환했다. 가닥을 빼내는 동작을 끝낸 뒤 작업 후의 결과 구도로 컷 전환한다. 이 구도에서는 정리한 손·도구·제거한 가닥을 제외해 모터를 가리지 않게 하고, 139.8583초부터 축과 모터가 함께 자유 회전하도록 연결했다.

29번 비교 컷에서는 개선 구조의 상승 가닥이 화면상 기존 롤러와 겹쳐 출처가 잘못 연결돼 보였다. 위쪽 비교 구도로 바꾸고 기존의 끝단 이동과 개선의 중앙 이동을 서로 다른 행에 유지했다. 기존 쪽 캡도 열어 끝단의 가닥이 숨지 않게 하고, 자막을 아래쪽 70% 높이로 옮겼다.

19번 손상 컷은 처음의 작은 회전·축소만으로는 변형이 잘 보이지 않아 보강했다. ‘손상될’ 58.7652초부터 고무 핀의 실제 메시 셰이프키와 개별 모의 곡선 굽힘을 진행해, 59.4858초에 접힌 상태를 보여 주도록 바꿨다.

시험 뒤 최종본에서는 가닥 제어점을 늘리고, 다발의 층과 폭을 달리했으며, 끝단 관찰 각도와 관리 장면의 손·도구 접점을 보완했다. 최종 40번은 절단 후 뻣뻣한 고리로 남지 않고 가닥이 풀리도록 추가 수정했다.

시험 음성의 끝은 다음 문장의 첫 음절이 잘리지 않도록 마지막 0.15초를 여백으로 처리했다. 최종 영상의 내레이션은 전체 원음을 유지한다.

2. 속도·시간축·자막·오디오 동기: 네이티브 24fps의 서로 다른 3435 상태를 최종143.125초로 연결했고 후편집 배속·보간·클립 반복이 없다. 동작의 시작·중간·결과를 시험본의 1초 및0.25초 프레임과 최종 주요 시점으로 확인했다. 원문264어절과 자막 순서가 일치하고 최종 AAC의 앞0–15초/뒤125–142초는 마스터 대비10ms 분석 단위에서 지연0ms다. 음성 설정1.0과 수치 검사만으로 전체 발화의 자연스러움을 인증하지는 않으며, 이 보고서는 전체 영상을 실시간으로 청취했다고 주장하지 않는다.
